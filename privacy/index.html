About Overseer

Overseer is an independent mobile companion for an existing Seerr server. You choose the server and sign in using an account supported by that server. The server owner controls server accounts, requests, reports, visibility, retention, notifications and downstream downloads. The app does not create a new developer-hosted account.

Signing in

Local and configured Jellyfin/Emby credentials are sent to your selected Seerr server for authentication. The app does not persist your password. Jellyfin Quick Connect uses temporary authorization data through Seerr. Plex sign-in opens Plex's browser page; a temporary Plex token is sent to Seerr and is not saved by this app. Temporary provider authorization data stays in memory during sign-in. Providers and browsers have their own privacy/storage practices.

Connection security

Use HTTPS whenever possible. If you deliberately choose HTTP, the connection to that server is unencrypted: passwords, tokens and session data can be read or changed by someone monitoring the network. The app requires acknowledgement before starting sign-in over HTTP. This acknowledgement does not encrypt the connection.

Information on your device

Connection settings use encrypted device storage. Persistent Android session cookies use a native encrypted store backed by Android Keystore; session-only cookies remain in memory. Account, media, request, issue and watchlist caches are held in memory; native image caches may also exist. Unfinished issue/comment drafts are not saved persistently. Session files and SecureStore settings are excluded from standard Android backups; broader manufacturer/cloud transfers are not guaranteed.

Information sent to your Seerr server

Requests, moderation actions, media issue descriptions and comments are sent to your Seerr server when you confirm them. The server may retain them, make them visible to permitted users or notify users. Keep sensitive information out of reports/comments. Signing out or uninstalling the app does not delete server accounts, requests, reports or comments; contact the server owner about those records.

Artwork, metadata and external links

Artwork loads directly from TMDB's HTTPS image host, which receives network information such as your public IP address and requested image path. Metadata is obtained through your chosen server. Trailer links open YouTube or a browser, whose own data practices apply. The public-release version of Overseer described by this policy does not request or display Rotten Tomatoes scores.

Analytics and support emails

No app analytics or automatic crash-reporting service is currently configured. If you voluntarily contact support, the chosen email/support service receives the information you send and follows its own data practices. Do not send passwords, cookies, tokens, API keys or private server/account information.

We use support emails to respond to your enquiry and retain them only as long as needed for support or legal obligations. Contact us to request deletion of your support correspondence.

Your controls and server records

Profile provides sign-out and confirmed server replacement. Successful sign-out clears active app account state while retaining the configured server. Server replacement removes the saved connection and signs out. These actions do not erase records held by the server, provider, browser or support service. A restored installation may require reconnecting and signing in again.

This website

This static website is hosted by GitHub Pages. It has no sign-in, forms, advertising, analytics scripts or embedded third-party content. GitHub receives network information when you visit and logs visitors' IP addresses for security purposes. See the GitHub Privacy Statement for its data practices.

Contact and policy updates

For support, privacy questions or a request to delete your support correspondence, contact OverseerMobileApp@runicsystems.net. Contact your Seerr server owner about accounts and records held on their server.

Changes to this policy will be published on this page with an updated effective date.

Overseer is an independent companion and is not an official Seerr application.
